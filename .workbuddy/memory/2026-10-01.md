### 关键决策
- 展示用纯函数（languageColor / formatStars / formatRelative）抽到 `repoFormat.ts`，避免 RepoCard 与 RepoActions 循环依赖，且相对时间口径只有一份。`lib/api.ts` 未导出 formatRelative，属 P6 地盘，未去改。
- 趋势图与「本周新增」都**在渲染进程用 UTC 现算**（`dateKey = toISOString().slice(0,10)`，与 `src/main/report.ts` 逐字同算法），不依赖 report IPC 往返，同步后图表立刻重绘。
- RepoActions 用 `useRef` 做**同步防重入锁**：仅靠 pendingAction（setState 异步）无法拦住同一 tick 的连点，实测连点确认按钮会弹两次 toast。加 ref 后连点 3 次只删 1 条。
- Dashboard 顶部两个按钮各自维护 syncBusy / enrichBusy，**不能共用 store 的全局 loading**，否则点同步时「AI 补全分类」会错显成"补全中…"。
- 未渲染「未知语言」下拉选项：`filters.language` 的 `null` 已被约定为「全部语言」且 filterRepos 严格相等比较，该筛选态在现有契约里无法表达，塞哨兵值只会筛出空列表。已在交付说明单列待 P6 确认。

### 环境坑（重要，下次直接照做）
- `MOCK_MODE=true npm run dev` 报 `Electron failed to install correctly` → `npx install-electron --no`。若 `fetch failed`，加 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`。
- **本机 shell 预设了 `ELECTRON_RUN_AS_NODE=1`**，会让 Electron 退化成纯 Node 并报
  `does not provide an export named 'BrowserWindow'`。启动前必须 `unset ELECTRON_RUN_AS_NODE`。
- 沙箱环境 GPU 进程会崩（`gpu_data_manager_impl_private.cc: FATAL`），加 `--disable-gpu --no-sandbox`。
- **窗口处于 hidden 时 rAF 被完全暂停**（回调 0 次），echarts 画不出 canvas，看起来像"图表坏了"。用 CDP `Page.setWebLifecycleState({state:'active'})` + `Emulation.setFocusEmulationEnabled` 即可恢复；与代码无关。
- 无头验证用 CDP：`--remote-debugging-port=9222`，`/json/list` 取 webSocketDebuggerUrl，然后 Runtime.evaluate / Page.captureScreenshot。
